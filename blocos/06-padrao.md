# 5. Padrão de saída

Técnica: few-shot. A forma das semanas. O tema dos exemplos não entra no plano.

EXEMPLO DE FORMATO — não use este tema no plano. O assunto abaixo existe só para mostrar a forma.

SEMANA A — Nome curto do foco
Foco: uma frase que nomeia o gap, não a ferramenta da moda.
Tempo: N h
Blocos:
- N h — ação com objeto (arquivo, página ou tabela)
- N h — segunda ação
- N h — revisão do que não tem fonte
Entregável: nome do artefato e o que ele contém
Como comprovar: o que um revisor abre
Gap atacado: nome do gap

SEMANA B — Nome curto do foco
Foco: uma frase.
Tempo: N h
Blocos:
- N h — ação
- N h — ação
Entregável: artefato
Como comprovar: verificação
Gap atacado: nome do gap
